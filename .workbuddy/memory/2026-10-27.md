### 结论性观点（面试可讲的）
- **harness 决定 Agent 能有多自由，workflow 决定 Agent 不能有多自由**——两者配合不是替代
- 重试必须看 `idempotent`：非幂等工具重试 = 重复副作用
- **幂等 ≠ 缓存**：幂等是"同一次操作重试不重复"，缓存是"不同时间同一查询复用"，混淆会出事
- 分布式锁 vs 幂等键：框架"从头重跑"语义下，**幂等是必须项、锁是可选项**
- 工具结果缓存：只对显式 `cacheable=True` + 完整参数哈希 + 短 TTL 的只读工具开，
  **写操作永远不进缓存**
- 不用 MQ 的三个理由：异步化（fire-and-forget 够）、事件驱动（需求不存在）、
  削峰（用户问答是同步的，削峰无意义）。真要上，先用"任务表 + FOR UPDATE SKIP LOCKED"
- 敏感操作回滚：DB 操作用真事务，跨系统用 Saga + 补偿表，**不可逆操作（发短信/扣款）
  别假装能回滚**
