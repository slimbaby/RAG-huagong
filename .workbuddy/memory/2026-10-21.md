# 2026-10-21 工作日志

## 固定流程（Workflow）模块 —— 第 1/2 期落地

### 背景与决策
- 需求：把"公司固定流程"接入 RAG 项目。
- 讨论后确认的需求画像：**生产工单/采购下单流** + **需要人工卡点** + **流程多且经常调整** + **要写公司 PostgreSQL** + **要发企微/邮件通知**。
- 由此定下技术形态：**YAML 声明流程骨架 + Python 只实现节点 handler**（`side_effect` / `notify` 两类需写代码，其余通用）。理由：流程多且常改 → 骨架必须改配置不改代码；写库/通知有复杂逻辑 → 逃不掉 Python。
- 决定 workflow 走**独立 API**（`/api/workflows/*`），不塞进 `/chat/query` —— 后者是无状态问答，前者是跨请求长事务。

### 关键决策：删除自研 Checkpointer 而非改造
- 查证 `app/tracing/checkpointer.py`（178 行）：**零调用点**（全项目无任何代码读 `deps["checkpointer"]`）、`app/api/checkpoints.py` 全是 404 空壳、前端零调用。
- 而它想干的活 tracer 已做得更好（它的 `duration_ms` 写死 0、无父子层级、无前端消费）。
- 结论：LangGraph 官方 checkpointer 负责它不可替代的职责（驱动图恢复执行），tracer 负责执行历史审计，两者分工不重叠 → **删掉自研的**。
- 选 `AsyncSqliteSaver` 而非 `SqliteSaver`：后者是同步 `sqlite3`，在 FastAPI async 事件循环里会阻塞 worker。

### 实现要点（踩过的坑）
1. **`GraphInterrupt` 继承自 `Exception`**，会被 `except Exception` 吞掉导致"挂起变失败"。引擎里定义 `_CONTROL_FLOW_EXCEPTIONS` 显式 re-raise。
2. **`slot_extract` 必须拆成两个节点**（抽取节点 + `__gate` 闸门节点）。若在同一节点里 interrupt，恢复时该节点从头重放 → LLM 被重复调用。拆开后闸门只做纯判断。
3. **`human_approval` 不在 `GENERIC_NODES` 表里**，判断顺序必须是"先判类型再查表"，否则报"未知节点类型"。
4. **`end` 类型节点不能串在线性主链上**，否则 `reject` 会在校验通过后也被执行。实现为"主链 = 排除 end 的步骤"，end 只能被 `goto`/`on_fail` 到达；主链末尾指向 `primary_end`（优先 id 为 `done` 的）。
5. **`rule_check` 失败时必须同时写 `status` + `error`**，否则后续 `end` 节点会把 failed 覆盖成 completed。
6. **checkpointer 单例不能按路径切换**：切换时 close 旧连接，已编译的 graph 仍持有它 → ainvoke 卡死。最终改为路径无关的单例 + 关闭只在应用 shutdown。
7. **aiosqlite 每个连接起一个后台线程**，pytest 退出时线程不结束会挂住整个测试进程。测试用 `pytest_asyncio.fixture` 在用例后 `close_checkpointer()`。
8. **`app/api/workflows.py` 的相对导入**：`.checkpointer` 会被解析到 `app.api.checkpointer`（同名文件），必须用 `..workflows.checkpointer` 绝对路径。
